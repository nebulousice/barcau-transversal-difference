# Lean 4 + Mathlib: what is formalized, and what could be

## What is formalized

**Nothing yet.** There is no Lean file for this result, and no statement in this repository has been checked by a proof assistant. Formalization is planned for after the written proof passes review. The sketches below are **uncompiled**, and the size estimates are rough.

## Feasibility

All of the proof is elementary finite group theory and counting. It uses no Kneser theorem, no analysis and no computation, so a full formalization looks feasible.

| Part | Feasible? | Approach | Rough size |
| --- | --- | --- | --- |
| Lemma F (one-dimensional cross-transversal bound) | **Yes** | Finsets in an additive commutative group; the pigeonhole argument of the proof | 100–200 lines |
| Theorem 1 (a), intrinsic form (no carries) | **Yes** | `G := ZMod (p^2) × ZMod (p^2)`; membership in $H$ as `p • g = 0` (Fact 2); the quotient `G ⧸ AddSubgroup.zmultiples g`; Lemma F twice; a disjoint-fibre count | 300–500 lines; the main cost is the quotient bookkeeping of step 3 and the count of step 5 |
| Bridge to the source's coordinates (the section $t_f$, the carry $c_u$, Lemmas A, B, C) | **Yes** | `ZMod.val` arithmetic for carries; then "$A_u$ on a line" implies the intrinsic hypothesis | 150–250 lines; the carry arithmetic is the only fiddly part |
| Corollaries 2 and 4 (with Lemma E for the upper bound) | **Yes** | Counting from Lemma A and Theorem 1 | 100–150 lines |
| Corollary 3 (equivalence with the case of no line direction) | **Yes** | An equivalence of two propositions | small |
| $p=3$ by brute force | No | `decide` over $9^8$ functions is out of reach, but Corollary 4 does not need it | — |

If only part is formalized, the order of value is: Lemma F, the intrinsic form of Theorem 1, Corollary 4.

## Suggested layout

In a Lake project with Mathlib, a folder such as `BarcauTransversal/`:
1. `CrossTransversal.lean`: Lemma F.
2. `LineDirection.lean`: the intrinsic form of Theorem 1 (a).
3. `Carry.lean`: $t_f$, $c_u$, Lemmas A, B, C, and the bridge.
4. `Corollaries.lean`: Corollaries 2, 3 and 4.

## Statements (uncompiled sketches)

Lemma F. The hypothesis says that every element outside $K$ has order greater than $q$.

```lean
-- UNCOMPILED SKETCH
open Pointwise in
theorem card_sub_ge_of_transversals {Z : Type*} [AddCommGroup Z] [DecidableEq Z]
    (K : AddSubgroup Z) (q : ℕ) (hq : K.index = q)
    (A B : Finset Z) (hA : A.card = q) (hB : B.card = q)
    (hAinc : ∀ a ∈ A, ∀ a' ∈ A, a - a' ∈ K → a = a')
    (hBinc : ∀ b ∈ B, ∀ b' ∈ B, b - b' ∈ K → b = b')
    (hO : ∀ e ∉ K, ∀ j : ℕ, 0 < j → j ≤ q → j • e ≠ 0) :
    2 * q - 1 ≤ (A - B).card := by
  sorry
```

Intrinsic form of Theorem 1 (a). The hypothesis on `g` says that every step of $T$ over $\pi(g)$ lies in the cyclic subgroup generated by `g`. By Lemma D (iv), for $g=[u]+\iota(a)$ this is exactly $A_u(f)\subseteq a+\langle u\rangle$.

```lean
-- UNCOMPILED SKETCH
open Pointwise in
theorem line_direction_bound (p : ℕ) [Fact p.Prime]
    (T : Finset (ZMod (p^2) × ZMod (p^2)))
    (hT : ∀ y, ∃! t, t ∈ T ∧ p • (y - t) = 0)          -- T is a transversal of H = pG
    (g : ZMod (p^2) × ZMod (p^2)) (hg : p • g ≠ 0)     -- g lies outside H
    (hstep : ∀ t ∈ T, ∀ t' ∈ T, p • (t' - t - g) = 0 → t' - t ∈ AddSubgroup.zmultiples g) :
    (2 * p - 1)^2 ≤ (T - T).card := by
  sorry
```

## What a formal proof would cover

- **With no extra trust:** Lemma F, Theorem 1 (a) in intrinsic form, its translation into the source's coordinates, and Corollaries 2, 3 and 4. Together these would make Corollary 4 ($\delta=25$ at $p=3$) a machine-checked theorem.
- **Not part of this result:** the numerical runs in `scripts/out/`. They are evidence only and would not be formalized.
- The general conjecture (the case with no line direction) is open, so there is nothing to formalize there.
